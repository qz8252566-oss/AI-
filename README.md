# なんでも図鑑カードメーカー

言葉を1つ入れると、AI が図鑑のデータを作り、カードにして画面に表示する Web アプリです。さくらのAI Engine の API（プログラムから AI を呼び出すための窓口）を使い、「AI をプログラムから動かす」ことを体験するための教材です。

<!-- 画像: カードが表示された画面 -->

## 最短の動かし方

1. このリポジトリの「Use this template」→「Create a new repository」で、自分のリポジトリを作る
2. 作ったリポジトリで「Code」→「Codespaces」→「Create codespace on main」を押す
3. ターミナルで `cp .env.example .env` を実行し、`.env` の `=` の後ろに取得したキーを貼って保存する
4. ターミナルで `npm start` を実行する
5. 開いたブラウザの画面で言葉を入れて「つくる」を押す

くわしい手順は、下のチュートリアルの 00 と 01 にあります。

## チュートリアル

全部で約90分です。00〜05 は順番に進めてください。06 は時間が余ったときや宿題に使います。

| [01 動かす](docs/01-run.md) | キーを貼ってカードを1枚作る。キーを人に見せてはいけない理由 | 10分 |
| [02 中をのぞく](docs/02-look-inside.md) | AI に送ったもの・返ってきたものを見る。API とは何か | 15分 |
| [03 カードを変える](docs/03-customize-card.md) | カードの項目を足す・消す・名前を変える | 15分 |
| [04 ルールと temperature](docs/04-rules-and-temperature.md) | AI へのルールを足す。答えのバラつきを変える | 15分 |
| [05 壊れた返事](docs/05-broken-json.md) | AI の返事が使えなくなる様子を見る。チェックとやり直しの意味 | 10分 |
| [06 発展](docs/06-challenge.md) | デザインを変える、モデルを比べる、対戦機能を作る など | 10分〜 |

学校の授業などで利用する場合は [講師向け資料](docs/instructor.md) を先に読んでください。

## ファイルの地図

| ファイル | 触ってよいか |
|---|---|
| `config.js` | ★ 書き換えてOK（カスタマイズの中心） |
| `.env` | ★ キーを貼る（人に見せない） |
| `public/index.html`、`public/style.css` | ★ 06 発展で書き換えてOK |
| `server.js`、`src/`、`public/app.js` | 読むだけでOK |
| それ以外 | 触らなくてOK |
