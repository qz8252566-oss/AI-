# 00 準備：自分専用の作業場所を作る（15分）

この章では、教材をコピーして自分のリポジトリを作り、ブラウザの中でプログラムを動かせる作業場所（Codespaces）を起動します。パソコンに何かをインストールする必要はありません。

必要なものは GitHub のアカウントだけです。

## 1. テンプレートから自分のリポジトリを作る

### やること

1. このリポジトリのページを開きます
2. 画面右上の緑色の「Use this template」ボタンを押し、「Create a new repository」を選びます
3. 「Repository name」に好きな名前を入れます（例：`my-card-maker`）
4. その下の公開範囲は「Private」を選びます
5. 画面下の「Create repository」を押します

<!-- 画像: Use this template ボタンの位置 -->
<!-- 画像: Create a new repository の入力画面 -->

### 結果

左上に `自分のユーザー名 / my-card-maker` と表示された、自分のリポジトリのページが開きます。

### なにが起きたか

リポジトリは、プログラムのファイルをまとめて入れておく箱です。教材の箱をまるごと複製して、自分の持ち物にしました。ここで何を書き換えても、教材の元のファイルや、ほかの受講者には影響しません。

Private にしておけば、リポジトリの中身は自分にしか見えません。GitHub の無料プランでも、Private のリポジトリで Codespaces を使えます。

## 2. Codespaces を起動する

### やること

1. 自分のリポジトリのページで、緑色の「Code」ボタンを押します
2. 開いた小窓の「Codespaces」タブを選びます
3. 「Create codespace on main」を押します

<!-- 画像: Code ボタンと Codespaces タブ -->

### 結果

新しいタブが開き、しばらく準備中の表示が続いたあと、左にファイルの一覧、右にファイルの中身、下に黒い文字の欄（ターミナル）が並んだ画面になります。初回は数分かかることがあります。

下のターミナルに `npm install` の文字が流れ、最後に `found 0 vulnerabilities` のような表示が出たら準備完了です。

<!-- 画像: 起動直後の Codespaces の画面全体 -->

### なにが起きたか

Codespaces は、GitHub が用意したクラウド上のパソコンを、ブラウザから操作できる仕組みです。この画面は VS Code というプログラム用のエディタで、中身は遠くのコンピューターで動いています。

起動するときに、このアプリが使う部品（express）が自動でインストールされました。設定は `.devcontainer/devcontainer.json` に書かれていますが、このファイルは触らなくて大丈夫です。

## 画面の見かた

この先の章では、次の名前で画面の場所を指します。

| 呼び方 | 場所 |
|---|---|
| エクスプローラー | 画面左のファイル一覧 |
| エディタ | 画面中央の、ファイルの中身が出る場所 |
| ターミナル | 画面下の、コマンドを打つ黒い欄。見当たらないときは、画面左上の「≡」→「ターミナル」→「新しいターミナル」で出せます |

## Codespaces を閉じたあと、また開くには

ブラウザのタブを閉じても、作業内容は残っています。自分のリポジトリのページで「Code」→「Codespaces」タブを開くと、作った Codespace の名前が出ているので、それを押すと続きから始められます。

## 無料で使い続けるために

GitHub の無料プランでは、Codespaces を動かせる時間とファイルを置ける容量に、毎月の上限があります。この講座の90分なら上限の数分の一で収まりますが、講座のあとも使い続けるときは、次のことを覚えておいてください。

- 作業を終えたら、自分のリポジトリのページで「Code」→「Codespaces」タブを開き、Codespace の名前の右の「…」→「Stop codespace」を押して止めます。止めている間は時間が数えられません。何もしなくても、30分操作しないと自動で止まります
- もう使わなくなった Codespace は、同じ「…」から「Delete」で削除します。残しておくと、容量の上限に数えられ続けます
- 上限に達しても、勝手にお金がかかることはありません。翌月まで Codespaces が使えなくなるだけです
