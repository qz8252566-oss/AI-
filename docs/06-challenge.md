# 06 発展：好きな課題に挑戦する（10分〜）

05 までで、このアプリのしくみはひととおり見ました。ここからは、次の4つから好きなものを選んで挑戦してください。時間内に終わらなくても大丈夫です。宿題として続けてもかまいません。

| 課題 | 触るファイル | むずかしさ |
|---|---|---|
| A. カードのデザインを変える | `public/style.css` | ★ |
| B. モデルを変えて結果を比べる | `config.js` | ★ |
| C. 絵文字を項目に加え、カードに大きく表示する | `config.js`、`public/app.js`、`public/style.css` | ★★ |
| D. 2枚のカードで対戦する「対戦」ボタンを作る | `public/index.html`、`public/app.js` ほか | ★★★ |

## A. カードのデザインを変える

`public/style.css` は、画面の見た目を決めるファイルです。書き換えて保存し、ブラウザを再読み込みすると反映されます。このファイルはサーバーを再起動しなくても反映されます。

手始めに、次のどれかを変えてみてください。

- `.card` の `border-radius: 12px;` を `0` や `30px` にする（カードの角の丸み）
- `.card-name` の `font-size: 1.4rem;` を大きくする（カードの見出しの文字の大きさ）
- `:root` の `--background: #f6f4ef;` を好きな色にする（画面の背景色）

色は `#` のあとに6けたの英数字で書きます。「カラーコード」で検索すると、色と数字の対応表が見つかります。

## B. モデルを変えて結果を比べる

`config.js` の `model` を変えると、答える AI が変わります。

1. `model: "gpt-oss-120b",` を `model: "preview/gemma-4-31B-it",` に変えて保存します
2. ブラウザを再読み込みし、いつもの言葉でカードを作ります
3. のぞき窓で、かかった時間とトークン数を、gpt-oss-120b のときと比べます

gemma のほうは、出力のトークン数がかなり少なくなります。gpt-oss-120b は答える前に「考える」分のトークンを使いますが、gemma は考える分を使わずにすぐ答えるためです。

`model` に使える名前の一覧は、さくらのAI Engine の説明書で確認してください。モデルによっては「JSON だけを返して」という指示を守らず、05 のように NG が続くものもあります。それもまた比べる材料になります。

名前を打ち間違えると「AI が受け付けてくれませんでした。config.js の model の名前を確認してください」と表示されます。

## C. 絵文字を項目に加え、カードに大きく表示する

まず `config.js` の `fields` に、次の1行を足します。

```js
    { key: "emoji", label: "えもじ", type: "text", maxLength: 2 },
```

これだけで、カードに「えもじ」の項目が出るようになります。ここから先は、その絵文字を大きく表示する工夫です。

- `public/app.js` の `makeCard` という関数が、カードを組み立てている場所です。`name` の項目だけ特別に見出しにしている部分を参考に、`emoji` も特別扱いしてみてください
- 大きさは `public/style.css` に新しいクラスを足して、`font-size` で決めます

## D. 「対戦」ボタンを作る

作ったカードから2枚を選び、数字の項目を比べて勝ち負けを出す機能を作ります。ここまでの内容より一段むずかしいので、Claude などの AI に手伝ってもらいながら進めてください。

AI に頼むときは、次のことを伝えると話が早く進みます。

- このアプリのファイル構成（README.md の「ファイルの地図」を貼るとよいです）
- 作りたい機能の具体的な内容（例：「作ったカードを2枚選んで『対戦』ボタンを押すと、つよさ と かわいさ の合計が大きいほうを勝ちとして表示したい」）
- 変更してよいファイル（`public/index.html`、`public/app.js`、`public/style.css`）

AI が出したコードは、貼りつける前に読んで、わからないところを AI に質問してみてください。どこを変えたかがわかっていれば、うまく動かないときにも直しやすくなります。
