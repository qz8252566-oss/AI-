# 03 カードを変える：項目を足す・消す・名前を変える（15分）

この章では `config.js` を書き換えて、カードの項目を自分好みに変えます。プログラムの本体には手を入れず、設定を変えるだけで AI への指示も自動で変わることを、のぞき窓で確かめます。

始める前に、ターミナルで `npm start` が動いていることを確認してください。止まっていたら、もう一度 `npm start` を実行します。

## 1. config.js を開く

### やること

エクスプローラーで `config.js` をクリックします。

### 結果

先頭に「★ このファイルは自由に書き換えてOK」と書かれたファイルが開きます。`fields:` の下に、カードの項目が1行に1つずつ並んでいます。

```js
  fields: [
    { key: "name",        label: "なまえ",   type: "text" },
    { key: "category",    label: "ぶんるい", type: "text" },
    { key: "power",       label: "つよさ",   type: "number", min: 1, max: 100 },
    { key: "cuteness",    label: "かわいさ", type: "number", min: 1, max: 100 },
    { key: "description", label: "せつめい", type: "text", maxLength: 80 },
  ],
```

### なにが起きたか

1行が、カードの項目1つ分の設定です。

| 書き方 | 意味 |
|---|---|
| `key` | AI とのやり取りで使う項目の名前。半角の英字で書きます |
| `label` | カードに表示する名前 |
| `type` | `"text"` なら文字、`"number"` なら数字 |
| `min`、`max` | 数字の項目の、いちばん小さい値と大きい値 |
| `maxLength` | 文字の項目の、いちばん長い文字数 |

## 2. 項目を足す

### やること

1. `description` の行の下に、次の2行を書き足します

   ```js
       { key: "place",       label: "すみか",   type: "text" },
       { key: "speed",       label: "はやさ",   type: "number", min: 1, max: 100 },
   ```

2. 保存します
3. ブラウザのアプリの画面に戻り、再読み込みします（Windows は F5、Mac は Cmd + R）
4. 「ペンギン」でカードを作ります

<!-- 画像: 2行を足した config.js -->

### 結果

保存した直後、ターミナルに `Restarting 'server.js'` と出て、サーバーが自動で起動し直します。

作ったカードには「すみか」と「はやさ」が増えています。「はやさ」には横棒のゲージもついています。

<!-- 画像: すみか・はやさが増えたカード -->

### なにが起きたか

のぞき窓を開き、「AI への指示（system）を読みやすくしたもの」を見てください。JSON の形の指示に、次の2行が増えています。

```
  "place": 文字,
  "speed": 1〜100 の整数
```

AI への指示は、`src/prompt.js` というプログラムが `config.js` の `fields` から毎回組み立てています。項目を足せば、指示の文章を自分で書かなくても AI に頼む内容が変わります。

## 3. 項目を消す・名前を変える

### やること

1. `cuteness`（かわいさ）の行をまるごと消します
2. `power` の行の `label: "つよさ"` を `label: "パワー"` に変えます
3. 保存して、ブラウザを再読み込みし、カードを1枚作ります

### 結果

「かわいさ」が消え、「つよさ」が「パワー」という表示に変わったカードができます。

### なにが起きたか

のぞき窓の指示からも `cuteness` の行が消えています。

一方、`label` を変えても、指示の中は `"power": 1〜100 の整数` のままです。AI とのやり取りで使うのは `key` のほうで、`label` は画面に出すための名前だからです。

## 書き間違えたときは

`config.js` で、行の終わりの `,`（カンマ）や `{ }` を消してしまうと、保存したときにターミナルに次の案内が出て、サーバーが止まります。

```
【config.js の書き方に間違いがあります】
13 行目か、その1つ前の行を見てください。
カンマ（,）、かっこ { } [ ]、ダブルクォート " が抜けていないかを確認します。
直して保存したら、Ctrl + C でサーバーを止めて、もう一度  npm start  を実行してください。
```

行番号は、プログラムが「おかしい」と気づいた場所です。実際の間違いは、その1つ前の行にあることがよくあります。この例では、12行目の終わりのカンマが消えていました。エディタの各行の左端に、行番号が表示されています。

案内にあるとおり、直して保存しても、サーバーは自動では起動し直しません。ターミナルで Ctrl + C を押してから、もう一度 `npm start` を実行してください。

## 自由に変えてみよう

ここまでの操作を使って、好きなカードを作ってみてください。

- `title` を変えて、図鑑の名前を変える（例：`"おかし図鑑"`）
- 「ねだん」「にんきど」など、図鑑に合った項目を足す
- 数字の項目の `max` を `10` にして、10段階にする

変えたあとに元の形に戻したくなったら、この章のはじめに載せた `fields` を見ながら書き直してください。
