# 01 動かす：キーを貼ってカードを1枚作る（10分）

00 で Codespaces が開いた状態から始めます。この章では AI を使うためのキー（APIキー）を設定し、アプリを起動して、図鑑のカードを1枚作ります。

## 1. キーを置くファイル（.env）を作る

### やること

1. ターミナルに次のコマンドを打ち、Enter キーを押します

   ```
   cp .env.example .env
   ```

2. エクスプローラーに `.env` が増えたことを確かめ、クリックして開きます
3. `SAKURA_AI_TOKEN=` の `=` のすぐ後ろに、取得したキーを貼ります。キーは `英数字とハイフン:英数字` の形をしています。`:` の後ろまで全部貼ってください
4. 保存します（Windows は Ctrl + S、Mac は Cmd + S）

貼ったあとの `.env` は、次のような1行になります（`xxxx` の部分が実際のキーです）。

```
SAKURA_AI_TOKEN=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx:xxxxxxxxxxxx
```

`=` の前後に空白を入れたり、キーを `"` で囲んだりしないでください。

<!-- 画像: キーを貼った .env（キーの部分はぼかす） -->

### 結果

エディタのタブに表示される `.env` の名前の横から、未保存を表す ● が消えます。

### なにが起きたか

`cp` は「コピーする」という意味のコマンドです。見本のファイル `.env.example` をコピーして、自分用の `.env` を作りました。

`.env` は、プログラムに渡す秘密の値を書いておくファイルです。このリポジトリでは、`.env` は GitHub に送らない設定（`.gitignore`）になっています。

## 2. アプリを起動する

### やること

ターミナルに次のコマンドを打ち、Enter キーを押します。

```
npm start
```

### 結果

ターミナルに次のように表示されます。

```
サーバーが起動しました。ポート 3000 で待っています。
```

少しすると、ブラウザに新しいタブが開き、「なんでも図鑑」の画面が出ます。

タブが自動で開かないときは、ターミナルの上に並んでいる「ポート」タブを押し、3000 の行の地球のマーク（ブラウザーで開く）を押してください。

<!-- 画像: ポートタブと地球のマーク -->

**うまくいかないとき**：ターミナルに【まだ .env ファイルがありません】や【.env にキーが入っていません】と出たら、表示された案内のとおりに直します。直したら、ターミナルで Ctrl + C を押してから、もう一度 `npm start` を実行してください。

### なにが起きたか

`npm start` で、このリポジトリの `server.js` というプログラムが動き始めました。これが「自分のサーバー」です。サーバーは、ブラウザからの注文を受け付ける店のようなもので、3000 番という受付窓口（ポート）で待っています。

サーバーは止めるまで動き続けます。止めたいときは、ターミナルをクリックしてから Ctrl + C を押します。

## 3. カードを作る

### やること

1. 画面の入力欄に「たこ焼き」と入れます
2. 右の「つくる」ボタンを押します

### 結果

「図鑑を書いています…」と表示され、数秒でカードが出ます。カードには「なまえ」「ぶんるい」「つよさ」「かわいさ」「せつめい」が並び、数字の項目には横棒のゲージがついています。

作ったカードは、画面下の「作ったカード」にもたまっていきます。好きな言葉で、何枚か作ってみてください。

<!-- 画像: たこ焼きのカード -->

### なにが起きたか

「つくる」を押すと、入れた言葉があなたのサーバーに届き、サーバーがさくらのAI Engine という AI のサービスに「この言葉の図鑑データを作って」と頼みました。AI が作ったデータを、ブラウザがカードの形に並べて表示しています。

同じ言葉でもう一度作ると、数字や説明が少し変わります。AI の答えは毎回同じとは限りません。このことは 04 と 05 で詳しく扱います。

カードの色は「ぶんるい」の文字から決まります。同じ分類のカードは同じ色になります。

## キーを人に見せてはいけない理由

キーは、AI のサービスに「この利用者は正規の利用者です」と証明する鍵です。家の鍵と同じで、持っている人は誰でもドアを開けられます。

- キーを知った人は、あなたになりすまして AI を使えます
- 使った分は、キーの持ち主の利用回数として数えられます。この講座のキーは全員で利用回数の上限を共有しているので、誰かが使いすぎると全員が使えなくなります

ですから、次のことはしないでください。

- キーをチャットや SNS に貼る
- キーをスクリーンショットに写す
- `.env` 以外のファイルにキーを書く（`.env` 以外のファイルは GitHub に送られることがあり、リポジトリを公開したときに人から見えてしまいます）

このアプリは、キーをブラウザに渡さないように作ってあります。その仕組みは次の章で見ていきます。
