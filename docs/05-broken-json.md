# 05 壊れた返事：AI の返事をチェックする理由（10分）

ここまで、AI は毎回 JSON の形で答えてくれていました。でも、それは「JSON だけを返してください」と頼んでいたからです。この章では、その頼みをわざと外し、AI の返事がプログラムで使えなくなる様子を見ます。

## 1. JSON の指示を外す

### やること

1. `config.js` の下のほうにある、次の行を探します

   ```js
     experimentNoJsonInstruction: false,
   ```

2. `false` を `true` に変えて保存します
3. ブラウザを再読み込みし、「たこ焼き」でカードを作ります

### 結果

いつもより長く待たされ（15秒ほど）、カードの代わりに赤い文字で次のメッセージが出ます。

> 3回やってみましたが、AI の返事をカードにできませんでした。のぞき窓で理由を見てみましょう

<!-- 画像: エラーメッセージが出た画面 -->

## 2. のぞき窓で理由を見る

### やること

のぞき窓を開き、「1回目」「2回目」「3回目」の部分を順に見ます。

### 結果

どの回も「返ってきたもの」に、表や見出しを使った長い説明文が入っています。

```
**たこ焼き（たこやき）**

| 項目 | 内容 |
|------|------|
| **なにもの？** | 小さく丸い形をした、熱々の粉もの料理です。… |
```

その下には「チェック結果：NG」と、「JSON として読めなかった（{ } が見つからなかった）」という理由が出ています。

また、「AI への指示（system）を読みやすくしたもの」を見ると、「次の形の JSON だけを返してください」から始まる部分がなくなっています。

<!-- 画像: NG が3回並んだのぞき窓 -->

### なにが起きたか

人が読むなら、この説明文はとてもよくできています。でもプログラムにとっては、どこが「なまえ」で、どこが「つよさ」なのかがわかりません。カードに並べるには、決まった名前で値が入った JSON が必要です。

このアプリは、AI の返事を受け取るたびに `src/validate.js` でチェックしています。

1. 前後の余計な空白や記号を取り除く
2. `{` から `}` までを取り出す
3. JSON として読めるか確かめる
4. `config.js` の `fields` の項目がそろっているか確かめる
5. 数字が範囲の外なら、範囲の中に直す
6. 文字が長すぎたら、切り詰める

1〜4 のどこかで失敗すると NG になり、AI にもう一度頼み直します。何回まで頼み直すかは `config.js` の `maxRetries`（はじめは 2）で決まっていて、最初の1回と合わせて最大3回頼みます。今回は JSON の指示がないので、3回とも NG になりました。

## 3. 元に戻す

### やること

`experimentNoJsonInstruction` を `false` に戻して保存し、ブラウザを再読み込みしてから、カードを1枚作ります。

### 結果

いつもどおり、数秒でカードができます。

## プログラムで AI を使うときの心がまえ

指示を戻せば、AI はほとんどの場合 JSON で答えてくれます。それでも、「ほとんど」は「必ず」ではありません。項目が1つ抜けたり、数字の代わりに「とても強い」と書いたりすることもありえます。

だから、AI の返事はそのまま使わず、

- 使える形になっているかをチェックする
- 直せるものは直す（範囲外の数字など）
- 直せないものは、やり直すか、使う人に知らせる

という手順をプログラムに入れておきます。のぞき窓で「自動で直したところ」が出ていたら、それは 5 や 6 のチェックが働いた跡です。

`src/validate.js` には、ここで説明した手順が日本語のコメントつきで書かれています。時間があれば読んでみてください。
