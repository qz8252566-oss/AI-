# 04 ルールと temperature：AI への頼み方を変える（15分）

03 ではカードの項目を変えました。この章では、項目はそのままで、AI への頼み方を2つの方法で変えます。1つは文章でルールを足す方法、もう1つは `temperature` という数字で答えのバラつきを変える方法です。

## 1. ルールを足す

### やること

1. `config.js` の `rules:` の部分を探します

   ```js
     rules: [
       "説明は小学生にもわかる言葉で書く",
     ],
   ```

2. 1行目の下に、次の1行を書き足します

   ```js
       "せつめいは関西弁で書く",
   ```

3. 保存して、ブラウザを再読み込みし、「消しゴム」でカードを作ります

### 結果

「せつめい」が関西弁になります。たとえば、次のような説明が返ってきます。

> 紙についた字や絵をぬくとこやで、間違えてもすぐ直せる便利な道具や。

<!-- 画像: 関西弁の説明が出たカード -->

### なにが起きたか

のぞき窓の「AI への指示（system）を読みやすくしたもの」を見ると、最後の「ルール:」の下に `- せつめいは関西弁で書く` が増えています。AI への指示（プロンプト）を1行変えただけで、返ってくる答えが変わりました。

ほかにも、次のようなルールを試してみてください。

- `"なまえはカタカナで書く"`
- `"つよさは、本当に強いものだけ 80 以上にする"`
- `"せつめいの最後に、豆知識を1つ入れる"`

AI はルールを必ず守るとは限りません。うまくいかないときは、言い方を変えたり、もっと具体的に書いたりすると、守られやすくなることがあります。

## 2. temperature を変えて作り比べる

### やること

1. 1で足した関西弁のルールの行を消して、保存します（違いを見やすくするためです）
2. `config.js` の `temperature: 0.7,` を `temperature: 0,` に変えて保存し、ブラウザを再読み込みします
3. 「たこ焼き」で3回続けてカードを作ります
4. `temperature: 1,` に変えて保存し、ブラウザを再読み込みします
5. もう一度「たこ焼き」で3回続けてカードを作ります
6. 画面下の「作ったカード」に並んだ6枚を見比べます

<!-- 画像: 6枚のカードを見比べた画面 -->

### 結果

「せつめい」の言い回しに注目してください。0 のときの3枚は似た文章になりやすく、1 のときの3枚は書き出しや言葉の選び方が変わりやすくなります。

ただし、0 にしても毎回まったく同じになるとは限りません。「つよさ」や「かわいさ」の数字も、0 のときに少し動くことがあります。

### なにが起きたか

AI は、文章を1語ずつ「次に来そうな言葉」を選びながら書いています。`temperature` は、その選び方の冒険度を決める数字です。

- 0 に近いほど、いちばん選ばれやすい言葉を選ぶので、答えが似てきます
- 1 に近いほど、ほかの言葉も選ぶようになるので、答えがバラけます

図鑑のように決まった形で答えてほしい用途では低め、アイデア出しのように色々な答えがほしい用途では高め、と使い分けます。

試し終わったら、`temperature` を `0.7` に戻しておきましょう。

## AI の答えは毎回変わる
